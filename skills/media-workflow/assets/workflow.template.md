## Discovery and inventory

Record examined pages/catalogues, source snapshots, item/variant mapping,
existing reusable assets, unresolved identities and excluded items with reasons.
Do not mark the inventory complete while claiming undiscovered items are covered.

## Production plan

Record selected tools/modes, common art direction, output requirements, job count,
pilot batch, per-job retry bounds, cost ceiling and any disjoint agent assignments.
Identify which actions are authorized and which must wait for missing inputs.

## Acceptance

Record subject/brand/variant/pack-size checks, text/quantity correctness,
composition, source fidelity, format/size checks, accessibility and page preview.
For audio/video add duration, intelligibility, timing and full-content review.

## Durable progress

Keep a timestamped account of in-flight jobs and output locations. Counts:
planned / saved / approved / rejected / blocked / validated / integrated / published.
Link attempt records. Never derive approval solely from a file count.

## Handoff

Record checks and exact revision, delivery mapping, original archive location and
verified backup state, remaining items, and the next concrete action. Record
publication only when actually authorized and verified.
